## 🚀 Featured Projects

### 🖋️ Project 1: Creative Writing Assistant
**Focus:** Multimodal workflows using ChatGPT & DALL-E.

This project demonstrates how to leverage AI as a creative partner. It focuses on maintaining narrative consistency and generating high-fidelity visual assets to match specific aesthetics.

<details>
<summary><b>Key Learning Objectives</b></summary>

* **Succinct Prompting:** Crafting high-density prompts for precise AI communication.
* **Workflow Management:** Utilizing sessions and threads to maintain narrative context.
* **Aesthetic Alignment:** Mastering DALL-E mechanics to ensure generated art matches intended styles.
</details>

---

### 🧠 Project 2: Dynamic Quiz Engine
**Focus:** Python API Integration & Educational Tool Design.

A Python-based application that interfaces with GPT-3 to generate custom multiple-choice exams. The system dynamically adjusts complexity and topic based on user parameters.

<details>
<summary><b>Key Learning Objectives</b></summary>

* **System Design:** Developing a Python script that bridges API responses with end-user requirements.
* **Prompt Iteration:** Analyzing the failure points of "naive" prompts versus expert-designed prompt structures.
* **Dynamic Parameterization:** Implementing logic to adjust question count, difficulty, and topic on the fly.
</details>

---

### 📊 Project 3: Natural Language to SQL (NL2SQL)
**Focus:** Data Engineering & SQL Query Synthesis.

An intermediate-level tool that bridges the gap between non-technical users and databases. It converts natural language questions into valid SQL queries to extract insights from real-world CSV data.



<details>
<summary><b>Key Learning Objectives</b></summary>

* **Data Preparation:** Transforming CSV files into Pandas DataFrames for local environment readiness.
* **Schema Simulation:** Crafting "SQL-like" table definition prompts to provide the LLM with database context.
* **Query Synthesis:** Constructing complex GPT prompts that return executable SQL code for real-time data extraction.
</details>

## 📈 Engineering Techniques Mastered
* **Context Window Management:** Keeping LLMs "on track" during long creative sessions.
* **Few-Shot Prompting:** Teaching the model specific output formats (like MCQ or SQL) through examples.
* **Programmatic LLM Interaction:** Moving beyond the chat interface and into automated Python-based API calls.
